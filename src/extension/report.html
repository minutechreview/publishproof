SEARCH & FETCH

Two different observations.

Search observes visibility in one result sample. Fetch observes extracted readable text. Neither proves Google ranking or every AI tool's understanding. Live use needs a server key and approved scope. Paid Agent and Browser APIs stay inactive.

Why not use Fetch for HTML tags?

TinyFish Fetch returns cleaned semantic content and may prefer OG title. Exact title, canonical, and JSON-LD checks here use public raw HTTP and a local DOM snapshot instead.
